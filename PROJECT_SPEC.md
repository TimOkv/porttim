# PROJECT SPECIFICATION: PERSONAL AI & FULLSTACK PORTFOLIO

## 1. Концепция и цель проекта
- **Назначение**: Персональное визитка-портфолио разработчика и AI-инженера.
- **Главная цель**: Произвести сильное первое впечатление за счет технологичного UI/UX, наглядно продемонстрировать системные результаты (кейсы и метрики) и направить потенциального клиента или партнера напрямую в личные сообщения Telegram.
- **Целевое действие (CTA)**: Кнопка перехода в Telegram (`https://t.me/<username>`) с предварительным текстом приветствия.

---

## 2. Технологический стек
- **Фреймворк**: Next.js 14+ (App Router, TypeScript)
- **Стилизация**: Tailwind CSS, PostCSS
- **Анимации & Интерактив**: Framer Motion
- **Иконки**: Lucide React
- **Шрифты**: Inter / Syne / JetBrains Mono (для тегов и цифр)
- **Утилиты**: clsx, tailwind-merge

---

## 3. Визуальный стиль и дизайн-система

### Палитра (Светлая неоново-ледяная гамма):
- **Background**: `#F8FAFC` (чистый, глубокий светлый фон с легким холодным подтоном).
- **Surface / Glass**: `rgba(255, 255, 255, 0.7)` с `backdrop-blur-md` и тонкой рамкой `rgba(255, 255, 255, 0.8)`.
- **Primary Accent**: `#0284C7` (насыщенный синий) и `#38BDF8` (небесно-голубой градиент).
- **Secondary Accent**: `#2563EB` (электрик блю) для кнопок и активных элементов.
- **Text Primary**: `#0F172A` (глубокий сланцевый для идеальной читаемости).
- **Text Secondary**: `#475569` (приглушенный серый для описаний).

### Визуальные эффекты:
- **Liquid Glass / Frost Glass**: многослойные стеклянные карточки с мягкими рассеянными тенями (`box-shadow: 0 20px 40px -15px rgba(2, 132, 199, 0.07)`).
- **Ambient Glow**: фоновые синие и лазурные градиентные размытые сферы (`blur-3xl`), создающие объем за портретом и карточками.
- **Микроинтеракции**: мягкий подъем карточек при ховере, реакция градиентных бордеров на курсор.

## 4. Структура страниц и компонентов

### 4.1. Header / Navigation
- Логотип / Имя разработчика с индикатором статуса: пульсирующая зеленая/голубая точка (`Available for new projects`).
- Быстрые ссылки: Проекты, Метрики, Стек.
- CTA-кнопка: "Связаться в Telegram" (акцентная стеклянная пилюля).

### 4.2. Hero Section
- **Левая колонка**:
  - Бейдж: `AI Solutions & Web Engineering`.
  - Заголовок: Крупный акцентный заголовок о создании готовых цифровых продуктов, нейросетевых агентов и сквозных веб-сервисов.
  - Подзаголовок: Опыт разработки от концепта и логики до интерфейса и развертывания.
  - Кнопка действия: "Обсудить проект" -> ведет в Telegram.
- **Правая колонка (Визуальный центр)**:
  - Вертикальный портрет с соотношением сторон ~ 3:4 / 4:5.
  - Анимация появления: плавный выезд снизу со scale-эффектом и легким пружинящим завершением (Framer Motion).
  - Стеклянная подложка-рамка с деликатным сине-голубым свечением по контуру.

### 4.3. Key Metrics (Блок ключевых цифр)
Интерактивные счетчики с запуском анимации при скролле (Framer Motion `useInView`):
1. **8+** — Реализованных цифровых систем и проектов.
2. **100%** — Автономия ключевых процессов в разработанных ботах и сценариях.
3. **< 2 недель** — Средний цикл сборки и запуска функционального MVP.
4. **24/7** — Бесперебойная работа внедренных AI-агентов.

### 4.4. Portfolio Showcase (Bento Grid)
Данные импортируются из `data/projects.ts`. Сетка из интерактивных карточек:

1. **Корпоративный веб-сайт (Многостраничный)**:
   - *Описание*: Архитектурный веб-ресурс со сложной структурой страниц, каталогом услуг и оптимизацией производительности.
   - *Стек*: Next.js, TypeScript, Tailwind.
2. **Высококонверсионный Landing Page #1**:
   - *Описание*: Промо-лендинг продукта с акцентным визуальным стилем и интерактивными элементами вовлечения.
3. **Высококонверсионный Landing Page #2**:
   - *Описание*: Специфический продуктовый лендинг с акцентом на быструю лидогенерацию.
4. **Автономный AI-агент поддержки**:
   - *Описание*: Интеллектуальный агент с подключенной базой знаний, анализом контекста диалога и сценариями маршрутизации запросов.
   - *Стек*: LLM APIs, Vector Stores, Python, n8n.
5. **Многофункциональный Telegram-бот #1**:
   - *Описание*: Бот автоматизации клиентского пути с обработкой входящих данных и интеграцией со сторонними сервисами.
6. **Telegram-бот для сервисных задач #2**:
   - *Описание*: Бот для мгновенных уведомлений, управления очередями задач и операционной синхронизации.
7. **Комплексная автоматизация бизнес-процессов #1**:
   - *Описание*: Сквозной пайплайн передачи данных между вебхуками, базами данных и сервисами оповещений на базе n8n и Docker.
8. **Автоматизация обработки данных #2**:
   - *Описание*: Автономный конвейер синхронизации сервисов без участия человека.
9. **Интерактивный Web-квест**:
   - *Описание*: Геймифицированный веб-проект с логикой квеста, ветвлением решений и вовлекающим сценарием.

## 5. Требования к коду и интеграции
- Все строковые тексты и массив кейсов хранить отдельно в `data/projects.ts` для легкого редактирования.
- Отзывчивая верстка: безупречное отображение на мобильных устройствах (портрет адаптируется по центру, bento-grid перестраивается в 1 колонку).
- Никаких тяжелых внешних библиотек, способных снизить оценку производительности в Lighthouse.
