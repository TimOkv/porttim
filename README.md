# TimA — AI & Web Engineering

Портфолио по `PROJECT_SPEC.md`: ледяная палитра, Liquid Glass, вертикальный портрет, Framer Motion, счётчики, фильтруемая bento-сетка из девяти кейсов и контакты Telegram.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Нужен Node.js 20.9 или новее.

```sh
npm run build
npm start
```

Если среда блокирует служебные порты Turbopack, используйте штатный альтернативный сборщик:

```sh
npm run build -- --webpack
npm run dev -- --webpack
```

## Контент

- `data/projects.ts` — тексты, метрики, категории, кейсы, стек и профиль.
- `public/portrait.jpg` — портрет TimA, копия исходного `Portret.jpg`. Next Image оптимизирует выдачу под размер экрана.
- `.env.example` — необязательные настройки имени, Telegram и локального пути к портрету. Для локальной настройки скопируйте файл в `.env.local`; на хостинге задайте переменные перед сборкой.
- По умолчанию интерфейс использует TimA и `@opskeeper`. Все CTA открывают личный диалог с черновиком приветствия. Сообщение автоматически не отправляется.
- Превью проектов созданы средствами CSS, это иллюстрации, а не скриншоты готовых продуктов. Кейсы и метрики взяты из предоставленной спецификации.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build -- --webpack
npm run test:e2e
```

Playwright проверяет десктоп и мобильный экран: загрузку портрета, ссылки, отсутствие горизонтального скролла, фильтрацию, модальный просмотр кейса, возврат фокуса, reduced motion, переключение стека и WCAG AA через axe. При необходимости установите Chromium: `npx playwright install chromium`.

Шрифты Inter Variable и JetBrains Mono Variable поставляются локально. В интерфейсе нет внешних запросов к шрифтовым сервисам и тяжёлых 3D-зависимостей.
