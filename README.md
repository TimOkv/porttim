# TimA — AI & Web Engineering

Сайт-портфолио: ледяная палитра, Liquid Glass, вертикальный портрет, Framer Motion. Секции идут в таком порядке: первый экран, полоса цифр, кейсы, «Обо мне», стек, контакты Telegram. `PROJECT_SPEC.md` — исходный документ о первой версии сайта; актуальное описание — здесь.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Нужен Node.js 20.9 или новее.

```sh
npm run build
npm start
```

Если среда блокирует служебные порты Turbopack, используйте штатный альтернативный сборщик:

```sh
npm run build -- --webpack
npm run dev -- --webpack
```

## Контент

Всё содержание лежит в `data/projects.ts`; в компонентах текстов нет.

- `profile`, `copy` — профиль и тексты интерфейса, включая пункты меню (`copy.nav`) и надзаголовки секций.
- `projects` — кейсы. Поля кейса: `id` (он же хвост короткого адреса `/tg/<id>`), `number`, `category` (фильтр: Web, AI & Bots, Automation), `label` (подкатегория на карточке, например «Web / EdTech»), `format`, `title`, `result` (выделенный результат: `text` и необязательное число `value`), `description`, `value` (ценность для бизнеса, показывается в окне кейса), `tags` и необязательный `url` — с ним в окне кейса появляется кнопка «Посмотреть проект».
- Карточки кейсов текстовые, без картинок: номер и подкатегория, название, выделенный результат, описание, формат, теги. Сетка ровная: три колонки, две на планшете, одна на телефоне.
- `metrics` — полоса цифр; первая цифра равна числу кейсов.
- `about` — блок «Обо мне»: надзаголовок, заголовок с акцентом, два абзаца (`paragraphs`), ряд из четырёх фактов (`facts`) и подпись кнопки (`cta`). Число кейсов и число направлений в фактах считаются из `projects`, руками не вписываются.
- `stack` — три группы стека. У группы: `icon` (`layers`, `workflow` или `sparkles`), `name`, `detail` (строка о пользе) и `items` — технологии. Новая технология добавляется одной строкой в `items`; группа с пустым `items` не показывается. Секция статична, нажимать в ней нечего.
- Десятый кейс — одна запись в `projects`: счётчик фильтра, цифра в полосе и факт в блоке «Обо мне» обновятся сами.
- `public/portrait.jpg` — портрет TimA, копия исходного `Portret.jpg`. Next Image оптимизирует выдачу под размер экрана.
- `.env.example` — необязательные настройки имени, Telegram и локального пути к портрету. Для локальной настройки скопируйте файл в `.env.local`; на хостинге задайте переменные перед сборкой.
- По умолчанию интерфейс использует TimA и `@opskeeper`. Имя аккаунта Telegram задаётся в одном месте — `lib/telegram.ts`. Все кнопки связи (шапка, первый экран, «Обо мне», окно кейса, контактный блок, плавающая кнопка) открывают личный диалог с черновиком приветствия. Сообщение автоматически не отправляется.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build -- --webpack
npm run test:e2e
```

Playwright проверяет десктоп и мобильный экран: загрузку портрета, ссылки, отсутствие горизонтального скролла, фильтрацию, модальный просмотр кейса, возврат фокуса, reduced motion, меню и номера секций, блок «Обо мне», группы стека и WCAG AA через axe. Тесты идут против `next start` на порту 3100 и переиспользуют живой сервер, поэтому перед прогоном остановите процесс на этом порту (`lsof -ti tcp:3100 | xargs kill`) и пересоберите проект. При необходимости установите Chromium: `npx playwright install chromium`.

Шрифты Inter Variable и JetBrains Mono Variable поставляются локально. В интерфейсе нет внешних запросов к шрифтовым сервисам и тяжёлых 3D-зависимостей.
