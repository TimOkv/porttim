# Тим Окунев — сайты, боты и автоматизация

Тёмный одностраничный сайт-резюме: крупные заголовки капсом, один сине-фиолетовый акцент, курсор-прожектор. Семь экранов идут в таком порядке: первый экран с цифрами, услуги, кейсы, «Почему я», подход, «Обо мне», контакт. `PROJECT_SPEC.md` — исходный документ о первой версии сайта; актуальное описание — здесь, подробное описание дизайна — в `docs/superpowers/specs/2026-10-04-redesign-design.md`.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Нужен Node.js 20.9 или новее.

```sh
npm run build
npm start
```

Если среда блокирует служебные порты Turbopack, используйте штатный альтернативный сборщик:

```sh
npm run build -- --webpack
npm run dev -- --webpack
```

## Контент

Всё содержание лежит в `data/projects.ts`; в компонентах текстов нет.

- `profile`, `copy` — профиль и тексты интерфейса, включая пункты меню (`copy.nav`) и заголовки секций.
- `projects` — кейсы. Поля кейса: `id` (он же хвост короткого адреса `/tg/<id>`), `number`, `category` (фильтр: Web, AI & Bots, Automation; подписи на странице — в `categoryLabels`), `title`, `done` (что сделано — строка на карточке), `result` (результат: `text` и необязательное число `value`), `details` (подробный текст в окне кейса) и необязательный `url` — с ним в окне кейса появляется кнопка «Посмотреть проект».
- Карточки кейсов компактные: номер и категория, название, строки «Сделано» и «Результат». Сетка ровная: три колонки, две на планшете, одна на телефоне. Клик открывает окно кейса с кнопкой в Telegram.
- `heroNumbers` — четыре цифры первого экрана; число проектов и число направлений считаются из `projects`.
- `services`, `why`, `processSteps` — плашки экранов «Услуги», «Почему я» и «Подход».
- `about` — блок «Обо мне»: два абзаца, метки и три факта. Имя берётся из `profile.name`.
- `stack` — список технологий. На странице они не называются: из массива считается только число «инструментов в работе». Новая технология — одна строка в `items`.
- Десятый кейс — одна запись в `projects`: счётчики фильтра и цифра первого экрана обновятся сами.
- `public/portrait.jpg` — портрет, копия исходного `Portret.jpg`. Next Image оптимизирует выдачу под размер экрана.
- `.env.example` — необязательные настройки: `NEXT_PUBLIC_PROFILE_NAME` (по умолчанию «Тим Окунев»), `NEXT_PUBLIC_TELEGRAM_USERNAME`, `NEXT_PUBLIC_MAX_URL`, `NEXT_PUBLIC_PORTRAIT_SRC`. Для локальной настройки скопируйте файл в `.env.local`; на хостинге задайте переменные перед сборкой.
- Имя аккаунта Telegram задаётся в одном месте — `lib/telegram.ts` (по умолчанию `@opskeeper`). Кнопки связи в шапке, на первом экране, в окне кейса, в контактном блоке и плавающая кнопка открывают личный диалог с черновиком; сообщение автоматически не отправляется.
- Ссылка на профиль в MAX задаётся в `lib/max.ts`. Кнопок MAX две: в контактном блоке и плавающая рядом с Telegram. Черновика у них нет.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Playwright проверяет десктоп и мобильный экран: загрузку портрета, ссылки в Telegram и MAX, отсутствие горизонтального скролла, порядок секций и меню, фильтр кейсов, окно кейса и возврат фокуса, цепочку «Подход», блок «Обо мне», курсор, режим без анимаций и WCAG AA через axe. Тесты идут против `next start` на порту 3100 и переиспользуют живой сервер, поэтому перед прогоном остановите процесс на этом порту (`lsof -ti tcp:3100 | xargs kill`) и пересоберите проект. При необходимости установите Chromium: `npx playwright install chromium`.

Шрифт Manrope Variable поставляется локально. В интерфейсе нет внешних запросов к шрифтовым сервисам и тяжёлых 3D-зависимостей.
