# Тим Окунев — сайты, боты и автоматизация

Одностраничное портфолио в утверждённом 9 октября 2026 дизайне по референсу Matthew: серый первый экран, бегущее имя за портретом, крупная типографика и контрастные секции. Порядок: первый экран, «Обо мне», кейсы, услуги, «Почему я», подход и контакт. Основной код — в `components/portfolio/`; `/prototype/matthew` теперь перенаправляет на `/`. `PROJECT_SPEC.md` и спецификация редизайна 2026-10-04 описывают прежние версии.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Нужен Node.js 20.9 или новее.

```sh
npm run build
npm start
```

Если среда блокирует служебные порты Turbopack, используйте штатный альтернативный сборщик:

```sh
npm run build -- --webpack
npm run dev -- --webpack
```

## Контент

Всё содержание лежит в `data/projects.ts`; в компонентах текстов нет.

- `profile`, `copy`, `portfolioCopy` — профиль, пункты меню, заголовки и тексты интерфейса.
- `projects` — кейсы. Поля кейса: `id` (он же хвост короткого адреса `/tg/<id>`), `number`, `category` (фильтр: Web, AI & Bots, Automation; подписи на странице — в `categoryLabels`), `title`, `done` (что сделано — строка на карточке), `result` (результат: `text` и необязательное число `value`), `details` (подробный текст в окне кейса) и необязательный `url` — с ним в окне кейса появляется кнопка «Посмотреть проект».
- Кейсы показаны строками со значком категории, названием и кратким описанием. Клик открывает окно с подробностями, результатом и личным черновиком Telegram.
- `services` — шесть услуг: сайты, боты, интеграции, системы под ключ, CRM-системы и веб-панели.
- `why`, `processSteps` — причины обратиться и четыре этапа работы. Номера этапов стоят только в кольцах; декоративная нумерация убрана.
- `about` — блок «Обо мне»: два абзаца, метки и три факта. Имя берётся из `profile.name`.
- `stack` — список технологий. На странице они не называются: из массива считается только число «инструментов в работе». Новая технология — одна строка в `items`.
- Десятый кейс — одна запись в `projects`: счётчики фильтра обновятся сами.
- `public/portfolio/tim-cutout.png` — портрет на прозрачном фоне; Next Image оптимизирует выдачу под размер экрана. Исходная фотография `public/portrait.jpg` и `Portret.jpg` сохранена.
- `.env.example` — необязательные настройки: `NEXT_PUBLIC_PROFILE_NAME` (по умолчанию «Тим Окунев»), `NEXT_PUBLIC_TELEGRAM_USERNAME`, `NEXT_PUBLIC_MAX_URL`, `NEXT_PUBLIC_PORTRAIT_SRC`. Для локальной настройки скопируйте файл в `.env.local`; на хостинге задайте переменные перед сборкой.
- Имя аккаунта Telegram задаётся в `lib/telegram.ts` (по умолчанию `@opskeeper`). Контактный блок и окно кейса открывают личный диалог с черновиком; сообщение автоматически не отправляется. Кнопка шапки ведёт к контактному блоку.
- Ссылка MAX задаётся в `lib/max.ts`; кнопки находятся в контактном блоке и окне кейса.

## Анимации и доступность

Имя движется независимо от прокрутки. Портрет использует параллакс, заголовки появляются из масок, факты растут при прокрутке. В «Почему я» — четыре SVG-сюжета с руками, ИИ, ракетой и диалогом; они реагируют на указатель, фокус клавиатуры и касание. Этапы работы остаются читаемыми, пока заполняются кольца и линия прогресса. Системная настройка уменьшения движения учитывается. Без JavaScript тексты, кейсы, факты и ссылки связи остаются видны.

На телефоне меню открывается отдельной кнопкой. Окно кейса удерживает клавиатурный фокус, закрывается по Escape и возвращает фокус к выбранному кейсу.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Действующий набор — `tests/portfolio-current.spec.ts`: главная страница и перенаправление прототипа, кейсы и фильтры, меню, диалог, ссылки Telegram/MAX, анимации, reduced motion, чтение без JavaScript, адаптивность и WCAG AA. `tests/portfolio.spec.ts` сохранён как проверка старого дизайна и не входит в текущий testMatch.

Playwright запускает новый `next start` на порту 3100; старые серверы не переиспользуются. Сборка должна уже существовать. Если порт занят, используйте `PORTFOLIO_TEST_PORT=3102 npm run test:e2e`. При необходимости установите Chromium: `npx playwright install chromium`.

Manrope Variable и Oswald поставляются локально; лицензия Oswald — `public/portfolio/OFL-Oswald.txt`. Внешние шрифтовые сервисы и тяжёлые 3D-зависимости не используются.

## Размещение в Timeweb Cloud App Platform

Репозиторий: https://github.com/TimOkv/porttim, ветка `main`.

При создании приложения подключите GitHub и предоставьте Timeweb доступ к этому
приватному репозиторию. Выберите Next.js и **включите поддержку SSR**: проект
использует серверные перенаправления `/tg` и оптимизацию изображений Next Image.
Режим статического сайта для текущего проекта не подходит.

| Параметр | Значение |
| --- | --- |
| Фреймворк | Next.js с поддержкой SSR |
| Node.js | 24.x (проверено локально) |
| Ветка | `main` |
| Путь до проекта | Корень репозитория |
| Установка зависимостей | `npm ci` (если панель запрашивает отдельную команду) |
| Команда сборки | `npm run build -- --webpack` |
| Команда запуска | `npm start` |
| Внутренний порт | 3000 по умолчанию; `next start` также учитывает переменную `PORT` |
| Путь проверки состояния | `/` |
| Автодеплой | Сборка по последнему коммиту |

Папку `out` указывать не нужно: приложение запускается сервером Node.js.
Все публичные настройки имеют значения по умолчанию, поэтому для первого запуска
переменные окружения не обязательны. При изменении имени, портрета или контактов
задайте соответствующие `NEXT_PUBLIC_*` до сборки и запустите новый деплой.
Файлы `.env.local`, ключи и каталог `secrets/` в GitHub не загружаются.

Выберите конфигурацию сервера и проверьте её стоимость в панели перед заказом.
После успешного деплоя откройте технический HTTPS-домен, проверьте главную,
портрет, фильтры кейсов, Telegram/MAX и перенаправление `/tg`.
Собственный домен можно привязать затем в настройках приложения.

Официальные инструкции: [Next.js и SSR](https://timeweb.cloud/docs/apps/deploying-frontend-apps/nextjs),
[создание приложения](https://timeweb.cloud/docs/apps/deploying-frontend-apps).
